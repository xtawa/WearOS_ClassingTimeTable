# Classing Functional To-Do

This note tracks user-facing product improvements only, excluding build, tooling, and environment work.

- [ ] 导入体验升级
提升文件导入、分享导入和冲突处理体验，让用户更容易把现有课表安全导入应用。

- [ ] 编辑模型扩展为停课 / 补课 / 调课
支持按单次、本周起或整门课处理课程变更，让真实教学变动能被准确表达。

- [ ] 同步状态诊断页
把手机、Wear 和云端的同步状态与失败原因汇总展示，帮助用户快速定位和修复同步问题。

- [ ] 提醒能力细化到课程级
允许按课程单独配置提醒开关和提前时间，让提醒更贴合不同课程的重要性和通勤场景。

- [ ] Wear 端可操作性增强
增强 Wear 上的同步反馈、快捷操作和下一节课交互，让手表端更像独立可用的工具。

- [ ] 搜索与筛选增强
补充按地点、教师、星期和时间段等维度的筛选，降低用户查找特定课程的成本。

- [ ] 备份、快照与撤销能力
在导入、批量修改和删除前后提供快照、恢复和撤销能力，减少误操作带来的损失。

Recommended first target: 编辑模型扩展为停课 / 补课 / 调课, together with automatic snapshots and undo support.
