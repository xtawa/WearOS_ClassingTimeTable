# Classing Functional To-Do

This note tracks user-facing product improvements only, excluding build, tooling, and environment work.

- [x] 导入体验升级
支持直接选择 `.ics` / `.json` 文件、从系统分享面板导入，以及保留当前的粘贴解析方式。
在导入前展示更清晰的预览、字段异常提示和冲突摘要，并允许用户按项跳过、继续或取消本次导入。

- [ ] 编辑模型扩展为停课 / 补课 / 调课
支持“仅本次”“从本周起”“整门课”三类修改范围，覆盖临时停课、补课、换教室、换时间等常见场景。
让用户能把教学周中的真实变动记录成结构化例外，而不是只能直接改写原始课程。

- [ ] 同步状态诊断页
汇总手机本地、Wear 端、云端三侧的最近同步时间、最后成功状态、当前数据来源和失败原因。
提供更明确的修复入口，例如重发到 Wear、重新拉取云端、重新下发配置或提示用户重新授权。

- [ ] 提醒能力细化到课程级
允许每门课单独设置提醒开关、提前时间和特殊提醒策略，而不是只依赖全局提醒配置。
优先覆盖早八、跨校区、重要课程等高频需求，并在通知里提供稍后提醒等快速操作。

- [ ] Wear 端可操作性增强
让 Wear 首页、磁贴和 complication 不只展示信息，还能更快进入下一节课详情、同步入口和状态查看。
补足同步中、数据过期、同步失败等反馈，让手表端在脱离手机时也能说明当前可用性。

- [ ] 搜索与筛选增强
在现有课程检索基础上增加地点、教师、星期、时间段、周次等筛选维度，并支持组合过滤。
优先服务“今天在某栋楼还有什么课”“某老师这周有哪些课”这类实际查找路径。

- [ ] 备份、快照与撤销能力
在导入、批量编辑、清空课表等高风险操作前自动生成本地快照，并允许按最近记录恢复。
为删除和批量覆盖提供短期撤销入口，减少误操作后只能依赖整包还原的情况。

Recommended first target: 编辑模型扩展为停课 / 补课 / 调课, together with automatic snapshots and undo support.
