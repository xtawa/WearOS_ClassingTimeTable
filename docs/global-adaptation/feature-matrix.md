# 国际版 Free / Pro 开发矩阵

产品决策基于本轮需求，价格与用户接受度待实验验证。基础建表、离线查课与首次完整建表流程保持免费；用户选择需要服务成本的功能时再解释资格与费用，不在完成第一张可用课表之前强制订阅。

| 能力 | Free 目标 | Pro / 成本边界 | 本轮状态 |
|---|---|---|---|
| 手工、ICS、JSON、备份导入 | 完整建表、逐项编辑、冲突警告 | 无首次建表订阅墙 | 本地代码与测试 |
| AB 周/日、5/6/8 日轮换、不规则日期、Lecture/Lab | 全部本地排课 | 不以复杂排课制造首次门槛 | 共用规则与编辑器已接入 |
| Next Class、Today、离线缓存 | 免费；显示成功同步时间与过期提示 | 无 | 手机/Wear 本地实现 |
| 手机基本 Widget、Wear Tile/Complication | 免费 | 无 | Widget/Tile 已改；设备验收待补 |
| 手机→Wear Data Layer | 免费；区分 queued/applied | 无 | ACK/基线回归 |
| 自有 WebDAV/Drive | 沿用现有配置与资格策略 | 不新增收费门槛 | 原有能力复用 |
| 官方托管云 | 沿用现有 Pro 资格校验 | 托管同步与恢复 | 现有后端权限保留 |
| 图片/PDF/文字 AI | 手工/ICS 回退始终可用 | 沿用现有点数/会员与模型合同；PDF 按页调用 | 首启草稿闭环；Global 后端仍禁用 |
| Canvas 原生只读 | PoC 手动选择事件；失败可手工/ICS | 自动周期同步、学校 OAuth 上线另评估 | 临时 token PoC；无后台 LMS 同步 |
| Homework | 独立于课时的只读预览 | 待访谈决定正式能力 | 不把截止时间建成课程 |
| 成绩统计、番茄钟、社交、泛 AI Planner | 延期 | 延期 | 无新增模块 |
| Apple Watch | 输出设计与设备验收要求 | iOS 工程另立项 | 本仓库只实现 Android/Wear |

实现约束：国际版会员资格必须由服务器验证购买结果，不能靠本机开关解锁。此矩阵不自动改变国内账户的既有权益，也不绕过现有 Global AI 或学校权限。实际收费文案使用 Play 返回的本地化价格，现阶段没有编造订阅价格。

付费墙位置：只在请求官方云/有成本 AI 等特定操作时展示；提示包含费用、当前资格、免费回退入口。现有首启可用手工/ICS 完成全过程。AI 多页处理中前面页面已成功调用的费用可能发生，后续页面失败仍不保存草稿到课表；上线前需要对这段费用说明做实测。
