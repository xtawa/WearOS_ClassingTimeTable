# ClassingTimeTable 项目说明（用于小米 MIMO 套餐申请）

ClassingTimeTable 是一款面向智能手表与手机协同场景的课程管理工具，核心目标是解决“上课信息分散、提醒不及时、跨设备不同步”这三类高频痛点。传统课表应用在手机端可用，但在手表端往往存在操作复杂、查看路径深、提醒延迟等问题；而本项目针对 Wear OS 小屏与抬腕即看场景进行重构，让用户在通勤、走路、课间等碎片时间中，能够用最低交互成本获取“下一节课是什么、在哪里、何时开始”的关键信息。项目同时支持提醒、周视图、搜索、课程详情与同步状态反馈，降低漏课与迟到概率。

核心逻辑流分为四层：第一层是数据建模与解析，统一课程、时间片、单双周规则、学期边界与例外课次；第二层是时态计算与状态判定，根据当前时间计算“未开始/进行中/已结束”；第三层是多端协同与同步仲裁，手机端负责配置与云端连接，手表端负责轻量消费与展示，通过数据层协议进行增量同步、冲突判定与回执；第四层是提醒执行链路，结合本地调度与补偿机制，保障到点触达。项目不依赖“长链推理”式 AI 决策，业务链路以可验证规则为主，确保稳定、可测试、可回放；但在工程协作范式上具备“多 Agent 协作”特征：可拆分为建模 Agent、同步 Agent、提醒 Agent、UI Agent 各自演进，再通过契约层集成，提升迭代效率与可维护性。
