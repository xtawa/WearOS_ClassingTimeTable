# 1.1.3 配置与交互

## 导入

导入入口仅提供 ICS / JSON / 手动导入三个按钮。每种方式拥有自己的二级页面、解析反馈与确认状态；返回先回到导入入口。拍照 AI 导入位于 JSON 页面，已有回复、思考折叠和课表校验保留。

## Ask AI

- + 浮层：拍照 / 上传图片 / 选择文件；文件使用原来的系统选择器。
- 普通附件允许 PDF、图片、文本、Office 文档、电子书、压缩包和其他数据文件；客户端与后端均排除可执行文件、音频和视频。后端根据实际文件特征校验，改扩展名不能绕过。
- 单个附件最多 20 MB，每条消息最多 4 个。默认保存 14 天。现代 Office / ODF / EPUB 提取有界文本；无法提取的二进制格式只提供元数据并要求转换，不宣称已经读取内容。
- 语音独立使用 MP3 转写接口：点击开始录音，图标变为红色停止按钮，再次点击停止并显示 Thinking；转写结果追加到草稿，不自动发送。录音与转写均可取消。
- 旧 voiceAutoSend 字段保留接口兼容，但本版不再自动发送，也不展示该开关。其他 Ask AI 设置继续使用云端 preferences 接口。

## 启动公告

Mobile 与 Wear 共用 client-common。客户端先加载本地课表，公告后台请求不阻塞离线看课；网络失败使用上次的公告缓存并校验有效期。

支持每次打开、每设备一次、每版本一次、累计次数上限、最短间隔、延迟、阅读时长、自动关闭、居中 / 底部 / 全屏、版本代码 / 名称、区域、平台及有效期。计数是应用安装数据中的本地计数，清除数据会重置；配置更新仅在启用 resetOnUpdate 时重置。单次打开最多依优先级展示 5 条。

图片使用有界下载与采样解码，Wear 最多展示 3 张、Mobile 最多 8 张，并限制同时解码请求数。旧 FEED 公告不会弹窗。应用自身拍照 / 文件选择器往返不会视为重新打开；旋转屏幕不会重复计数。
