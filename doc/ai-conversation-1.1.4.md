# 1.1.4 Ask AI 对话体验与拍照修复

- 推荐提示词改为独立、有分界线的横向区域，可在该区域或 Ask AI 设置中隐藏。显示开关通过账号偏好 API 同步到其他设备，隐藏后停止请求生成，自动刷新选项仍保留。
- 模型选择改为紧凑下拉，保留星标及模型描述。发送框使用更短的提示语，点推荐只填入草稿。
- 对话消耗点数使用中性文字，不再作为错误提示。阅读旧消息时不强制跳到新消息，可通过“查看最新消息”返回末尾。
- 推荐提示词本地缓存升级为 v2，配合后端新策略，避免继续显示旧策略生成的无依据问题。
- Ask AI 拍照文件使用 `cache/ai_photos/`，与既有 FileProvider 配置一致，修复“Failed to find configured root”。文件共享范围仍只包含照片及更新下载目录；拍照失败显示可理解的提示。

## 后端依赖

发布客户端前先部署配套后端：`showPromptSuggestions` 默认开启，支持逐字段 PATCH 与账号同步；隐藏时提示词接口不调用模型、不计生成额度。已开始的生成可能仍计费。

该账号偏好服务独立于课表云同步权限，Free、Legacy、Pro 都可同步自己的 Ask AI 设置。

## 验证与版本

Mobile/Wear 版本统一为 `1.1.4 (114)`。新增 FileProvider 可写 URI 的 Robolectric 回归测试，以及旧设置兼容和显示开关序列化测试。Android 单元测试、lint 和发布构建在 GitHub Actions 上执行，避免占用业务服务器编译资源。
