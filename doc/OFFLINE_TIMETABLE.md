# 离线课表与导入反馈

移动端和 Wear 的课程查看均以本机保存的课表为来源，不依赖网络、登录刷新、会员验证或手机连接。首次安装没有课表时，需要先导入或成功同步一次；数据保存后，断网和重新启动仍可查看。

- 移动端在启动时先读取本地 SharedPreferences 里的课程、调课和恢复快照，然后后台刷新账号与云同步。未启用 Pro 云同步、网络失败或会话过期均不清空这些课程。旧版 `lessons_json` 也在本机完成迁移。
- Wear 使用本地 Room 数据库计算今天、下一节、每周课表、搜索与详情，云端或手机同步是独立后台任务。同步失败会显示提示和重试按钮，不替换本地课程列表；重试过程中课程也保持可见。
- Ask AI、登录和云同步仍需要网络，离线查看课表不会改变云同步的会员权限。

导入反馈按 ICS、JSON 和手动导入分别保存。JSON 错误和警告只出现在 JSON 区域，手动导入结果只出现在手动区域。确认按钮校验当前预览来源，编辑原始内容使对应预览失效；清空 ICS 输入不会删除 JSON 输入或 JSON 预览。

回归测试覆盖 Wear 启动时网络失败、同步未完成、连续重试和重新打开时保持课程，以及移动端仅从持久化数据恢复课程、调课、快照和旧版数据迁移。
