产品概览

Classing Time Table 是一个跨平台课程表应用，包含移动端管理端和 WearOS 穿戴端， 通过 Google Wearable Data Layer 实现数据同步，支持多格式课程数据导入。

01
WearOS 原生体验
基于 Jetpack Compose for Wear 开发，完美适配圆形/方形屏幕， 支持 ScalingLazyColumn 滚动、表盘 Complication 集成。
02
无缝同步机制
通过 Google Wearable Data Layer 实现手机与手表实时同步， 支持离线队列、自动重试、同步状态反馈。
03
智能冲突检测
自动检测课程时间冲突、周次重叠，支持单双周规则判断， 在导入时实时反馈异常数据。
04
多格式数据导入
支持 ICS 日历格式和 JSON 自定义格式，内置容错解析逻辑， 自动识别多种字段命名规范。

核心功能

从表盘到课程详情，覆盖用户完整的课程表使用场景。

CB
表盘 Complication
通过 NextClassComplicationService 实现表盘集成， 在表盘上直接展示下一节课信息，支持短文本和长文本两种展示模式。 数据由 NextClassSnapshotProvider 实时提供，包含课程名称、 时间、地点、倒计时等关键信息。
HS
首页仪表盘
WearOS 首页展示日期、周数、同步状态、下一节课倒计时、今日课程列表， 以及课程热力图。使用 ScalingLazyColumn 实现圆形屏幕优化滚动， 支持快速操作入口（周视图、搜索、设置）。
WV
周课表视图
完整的一周课程表展示，支持按周次切换，显示每天的课程安排。 课程卡片展示时间、地点、教师信息，支持点击查看详情。
SD
课程详情
详细课程信息展示，包括课程名称、教师、教室、时间范围、周次规则、 备注等。支持收藏、编辑操作。

WearOS 特色

针对穿戴设备的特性进行深度优化，提供符合 WearOS HIG 的用户体验。

01
圆形屏幕适配
使用 Jetpack Compose for Wear 的 ScalingLazyColumn， 自动适配圆形屏幕的边缘裁剪，内容始终保持在可视区域内。
02
表盘集成
通过 Complication Data Source API 提供实时课程信息， 用户无需打开应用即可查看下节课。
03
手势操作
支持 WearOS 标准手势：轻触选择、长按操作、滑动导航， 符合用户对穿戴设备的操作习惯。
04
低功耗设计
优化数据同步频率，减少后台唤醒，延长手表续航。 Complication 更新采用按需策略。

DET
自动检测机制

detectWearAutoSyncPlan() 函数根据已安装的 WearOS 伴侣应用版本， 自动选择最佳同步模式：

  • CN / LE 版本：使用 SOURCE_WEAROS_APP 模式，通过 WearOS 应用通道同步
  • Global 版本：使用 SOURCE_WEARABLE_API 模式，通过 Google Wearable API 同步
检测逻辑：扫描 com.google.android.wearable.app.cn 和 com.google.android.wearable.app 包， 通过包名后缀和版本号中的 le 标识判断区域版本。
CON
课程冲突检测

detectLessonConflicts() 函数实现完整的课程冲突检测逻辑， 同时考虑时间重叠和周次规则：

internal fun lessonsOverlap( first: LessonUi, second: LessonUi ): Boolean { // 1. 检查是否同一天 if (first.dayOfWeek != second.dayOfWeek) return false // 2. 检查时间区间是否重叠 if (!(first.startTime < second.endTime && second.startTime < first.endTime)) { return false } // 3. 检查周次规则是否重叠 return weekRulesOverlap(first, second) }

weekRulesOverlap() 函数判断周次规则冲突：

internal fun weekRulesOverlap( first: LessonUi, second: LessonUi ): Boolean { // 周次区间不重叠 if (first.endWeek < second.startWeek || second.endWeek < first.startWeek) { return false } // 任意课程为全周 if (first.weekParity == ALL || second.weekParity == ALL) { return true } // 单双周相同则冲突 return first.weekParity == second.weekParity }

冲突检测结果用于导入预览和异常提醒：

检测类型 检测方法 状态
时间冲突 同天 + 时间重叠 冲突
周次区间重叠 endWeek >= startWeek 正常
单周 vs 单周 weekParity == ODD 冲突
单周 vs 全周 weekParity == ODD vs ALL 部分

数据导入

支持 ICS 日历格式和 JSON 自定义格式导入，内置容错解析逻辑， 自动识别多种字段命名规范。

ICS
ICS 日历导入
通过 IcsImportParser 解析标准 ICS 文件，提取课程名称、 时间、地点、描述等信息，自动转换为课程数据模型。
JSON
JSON 格式导入
parseJsonToLessons() 支持多种字段命名规范的容错解析：
  • 标题：title / name / courseName
  • 教师：teacher / instructor
  • 地点：location / classroom
  • 时间：startTime / start / startMinute
  • 周次：startWeek / weekStart / fromWeek
  • 单双周：weekParity / parity / oddEven

支持中英文周次标识（奇数周 / ODD / 单周）。

BCK
备份与恢复

buildScheduleBackupJson() 生成标准备份文件，格式版本为 classingtime_backup_v2， 包含：

  • 基础课程列表（courses）
  • 课程例外（exceptions）—— 调课、停课记录
  • 周数模式（weekNumberMode）
  • 学期起始日期（semesterWeekStartDate）
  • 时区信息（timezone）
parseScheduleBackupJson() 支持 v1 和 v2 版本的向后兼容解析， 自动识别并适配不同版本的格式差异。

Kotlin + Compose

同步
